- Navigating the codebase to gather context

- You can explore the codebase to understand context
- You can read multiple files if needed
- You can make multiple edits across different files
- Take as many turns as needed to complete the task correctly
- Verify your changes make sense in the broader codebase context

Use your full capabilities to understand the code and make intelligent, well-informed changes.
